# 官方动作序列：录制与播放

用途：不训练、不写 IK、不写运动规划。  
只用 XLeRobot host-client 的官方 `get_observation()` 和 `send_action()`：

- 录制：按时间读取当前手臂关节位置。
- 播放：按原时间把这些关节位置发回 host。

## 1. 录制前启动树莓派 host

现在推荐直接用普通 host。录制工具会在开始录制时自动释放对应手臂，录完后自动恢复上力，所以不需要每次重启 host：

```bash
cd ~/xlerobot-dev/lerobot
source .venv/bin/activate
unset XLEROBOT_PASSIVE_LEADER_ARM
python -m lerobot.robots.xlerobot.xlerobot_host
```

运行逻辑：

- 开始录制：Windows client 给 host 发 `set_arm_torque(enabled=false)`。
- 录制过程：只读取 host-client observation 里的手臂关节位置。
- 录制结束：Windows client 给 host 发 `set_arm_torque(enabled=true)`。
- 播放动作：继续用官方 host-client `send_action()` 发送录下来的关节目标。

旧方式也还能用。如果你想手动让某只手臂一直保持被动，可以在 host 启动前设置：

```bash
export XLEROBOT_PASSIVE_LEADER_ARM=right
python -m lerobot.robots.xlerobot.xlerobot_host
```

或者：

```bash
export XLEROBOT_PASSIVE_LEADER_ARM=left
python -m lerobot.robots.xlerobot.xlerobot_host
```

或者：

```bash
export XLEROBOT_PASSIVE_LEADER_ARM=both
python -m lerobot.robots.xlerobot.xlerobot_host
```

说明：

- `right`：只释放右臂，其他部位正常受控。
- `left`：只释放左臂，其他部位正常受控。
- `both`：同时释放左右臂，适合录制双臂展示、双臂举起、双臂回位等动作。
- 旧方式下播放动作前要退出 host，重新用普通模式启动 host，否则手臂还是松开的，不会执行动作。

## 2. 命令行录制

右臂录 5 秒：

```powershell
cd E:\lerobot
E:\lerobot\envs\lerobot-gpu\Scripts\python.exe E:\lerobot\robocrew_client_agent\录制官方动作序列.py wave_hello --arm-side right --seconds 5 --fps 20
```

录制时，在 5 秒内手动摆动手臂。

左臂录 5 秒：

```powershell
E:\lerobot\envs\lerobot-gpu\Scripts\python.exe E:\lerobot\robocrew_client_agent\录制官方动作序列.py left_wave --arm-side left --seconds 5 --fps 20
```

双臂同时录 5 秒：

```powershell
E:\lerobot\envs\lerobot-gpu\Scripts\python.exe E:\lerobot\robocrew_client_agent\录制官方动作序列.py both_show --arm-side both --seconds 5 --fps 20
```

动作会保存到：

```text
C:\Users\10775\.cache\robocrew\motions
```

## 3. 命令行播放

播放前树莓派 host 必须恢复正常控制模式：

```bash
unset XLEROBOT_PASSIVE_LEADER_ARM
python -m lerobot.robots.xlerobot.xlerobot_host
```

Windows 播放：

```powershell
E:\lerobot\envs\lerobot-gpu\Scripts\python.exe E:\lerobot\robocrew_client_agent\播放官方动作序列.py wave_hello
```

播放双臂动作：

```powershell
E:\lerobot\envs\lerobot-gpu\Scripts\python.exe E:\lerobot\robocrew_client_agent\播放官方动作序列.py both_show
```

## 4. LLM Agent 中使用

启动 Agent：

```powershell
E:\lerobot\envs\lerobot-gpu\Scripts\python.exe E:\lerobot\robocrew_client_agent\run_robocrew_client_agent.py
```

可说：

```text
列出录制好的动作
播放 wave_hello
录制右臂动作 try_pick_coke 8 秒
录制双臂动作 both_show 5 秒
播放 both_show
```

建议先录这些：

```text
wave_hello
right_reach_forward
try_pick_coke
place_to_basket
right_home
both_show
```
