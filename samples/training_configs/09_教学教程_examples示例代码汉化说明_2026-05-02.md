这些内容不适合直接翻译。比如 `left_arm_shoulder_pan.pos`、`XLerobotClientConfig`、`send_action`、`get_observation` 都是程序真正依赖的名字，改成中文会直接破坏代码。

## 为什么不直接全部改成中文变量

LeRobot/XLeRobot 的动作链路依赖固定字段名：

```text
observation.xxx.pos
action.xxx.pos
x.vel
y.vel
theta.vel
left_arm_shoulder_pan
right_arm_gripper
head_motor_1
```

这些字段名会在 robot、host、client、dataset、rerun、model policy 之间传递。后续你把示例改成 host/client 模式时，Windows client 发出去的 action key 必须和树莓派 host 里的机器人配置完全一致。

所以正确做法是：

```text
注释和说明可以中文化
字段名和 API 名必须保持英文原样
```

## 改成 host/client 时的最小替换思路

本地直连模式通常是：

```python
from lerobot.robots.xlerobot import XLerobot, XLerobotConfig

robot_config = XLerobotConfig()
robot = XLerobot(robot_config)
```

host/client 模式客户端通常改成：

```python
from lerobot.robots.xlerobot import XLerobotClient, XLerobotClientConfig

robot_config = XLerobotClientConfig(
    remote_ip="192.168.10.240",
    id="my_xlerobot_pc",
)
robot = XLerobotClient(robot_config)
```

树莓派端先运行 host：

```bash
cd ~/xlerobot-dev/lerobot
source .venv/bin/activate
python -m lerobot.robots.xlerobot.xlerobot_host
```

Windows 端再运行 client 示例。

## 后续改写时的安全顺序

建议每个示例都按这个顺序改：

```text
1. 只改 robot import 和 robot_config，让示例连到树莓派 host。
2. 先 get_observation，确认能读到关节和摄像头数据。
3. send_action 先只发一个很小的关节动作。
4. 再接键盘、手柄或 VR 输入。
5. 最后才加入底盘速度、双臂联动、模型策略。
```

尤其注意：

```text
树莓派 host 负责真实硬件、串口、电机和摄像头。
Windows client 负责键盘/手柄/模型/训练/推理。
client 只发送 action，不直接碰树莓派串口。
```
