# XLeRobot 官方示例运行评估

日期：2026-05-01  
重点文件：`E:\lerobot\XLeRobot\software\examples\5_xlerobot_teleop_xbox.py`  
当前架构：树莓派运行 host，Windows 运行 client / 遥控 / 训练

## 1. 结论

官方示例可以作为主要路线参考，但不能把 `5_xlerobot_teleop_xbox.py` 原样直接放在 Windows 上运行来控制当前机器人。

原因很简单：

```text
当前机械臂、底盘、摄像头都接在树莓派上。
而官方 5_xlerobot_teleop_xbox.py 默认使用 XLerobot 本地直连模式。
```

也就是说，这个示例默认会在运行它的机器上寻找：

```text
/dev/ttyACM0
/dev/ttyACM1
```

如果它运行在 Windows 上，就找不到这些树莓派 Linux 设备路径，也不能直接访问接在树莓派上的 Feetech 总线。

## 2. 官方示例分成两类

### 2.1 本地直连类示例

例如：

```text
5_xlerobot_teleop_xbox.py
4_xlerobot_teleop_keyboard.py 的默认路径
```

这类脚本通常这样创建机器人：

```python
robot_config = XLerobotConfig()
robot = XLerobot(robot_config)
```

含义：

```text
运行脚本的机器必须直接连接舵机控制板。
```

适合：

```text
树莓派本地运行
或者一台 Linux 电脑直接 USB 连接机器人硬件
```

不适合当前：

```text
Windows 运行脚本，树莓派连接硬件
```

### 2.2 host/client 远程类示例

XLeRobot 代码里已经包含：

```text
xlerobot_host.py
xlerobot_client.py
XLerobotHostConfig
XLerobotClientConfig
```

这类模式才适合当前架构：

```text
树莓派:
  XLerobotHost + XLerobot

Windows:
  XLerobotClient + 键盘/手柄/模型
```

## 3. 当前应该采用的官方路线

树莓派端继续运行官方 host：

```bash
cd ~/xlerobot-dev/lerobot
source .venv/bin/activate
python -m lerobot.robots.xlerobot.xlerobot_host
```

Windows 端应该使用官方 client 类：

```python
from lerobot.robots.xlerobot import XLerobotClient, XLerobotClientConfig

robot_config = XLerobotClientConfig(remote_ip="192.168.10.240", id="my_xlerobot_pc")
robot = XLerobotClient(robot_config)
robot.connect()
```

然后把 Xbox/键盘/模型产生的 action 交给：

```python
robot.send_action(action)
```

这样更贴近官方 host/client 结构，也符合我们现在的硬件连接方式。

## 5. 关于 Xbox 示例

`5_xlerobot_teleop_xbox.py` 当前默认逻辑：

```text
pygame 读取 Xbox 手柄
XLerobot 本地连接硬件
SO101Kinematics 做左右臂 IK
robot.send_action(action) 直接发给本地机器人
```

如果想在当前架构中使用它，应该做一个 client 版本：

```text
pygame 读取 Xbox 手柄
XLerobotClient 连接树莓派 host
SO101Kinematics 做左右臂 IK
robot.send_action(action) 通过 ZMQ 发给树莓派
```

这个改造不需要改变树莓派 host 主逻辑。

## 6. 为什么不建议直接在树莓派上跑 Xbox 示例

理论上，如果 Xbox 手柄蓝牙连接到树莓派，且树莓派能通过 pygame 读到手柄，那么可以在树莓派上跑本地直连示例。

但不推荐作为主路线：

```text
1. 树莓派性能有限。
2. pygame/蓝牙/桌面输入在树莓派上更容易遇到权限和输入设备问题。
3. 后续训练、模型推理、可视化都在 Windows 上更合适。
4. 当前已经确定要让树莓派只做 host。
```

因此更推荐：

```text
树莓派只跑 host。
Windows 读取 Xbox 手柄，并通过 XLerobotClient 控制机器人。
```
