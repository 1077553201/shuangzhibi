# XLeRobot Xbox 示例改写为 Host/Client 模式教程

日期：2026-05-01  
原始官方示例：`E:\lerobot\XLeRobot\software\examples\5_xlerobot_teleop_xbox.py`  
新增最小示例：

```text
E:\lerobot\host_client_examples\simple_xlerobot_host_runner.py
E:\lerobot\host_client_examples\simple_xlerobot_client_control.py
```

## 1. 目标

官方 Xbox 示例默认是“本地直连硬件”模式：

```text
Xbox 手柄
  -> pygame
  -> XLerobot
  -> 本机 /dev/ttyACM0、/dev/ttyACM1
  -> 机器人硬件
```

我们现在要改成：

```text
Xbox 手柄
  -> Windows pygame
  -> XLerobotClient
  -> 局域网 ZMQ
  -> 树莓派 XLerobotHost
  -> XLerobot
  -> /dev/ttyACM0、/dev/ttyACM1
  -> 机器人硬件
```

核心思想：

```text
保留官方 Xbox 示例里的手柄映射、IK、action 生成逻辑。
只把 robot 对象从本地 XLerobot 换成远程 XLerobotClient。
```

## 2. 原始 Xbox 示例为什么不能直接在 Windows 跑

原始文件里核心代码是：

```python
from lerobot.robots.xlerobot import XLerobotConfig, XLerobot

robot_config = XLerobotConfig()
robot = XLerobot(robot_config)
robot.connect()
```

这代表：

```text
当前运行脚本的机器必须能直接访问机器人硬件端口。
```

在 Linux/树莓派上，默认端口是：

```text
/dev/ttyACM0
/dev/ttyACM1
```

但 Windows 没有这些 Linux 设备路径，而且机器人硬件现在接在树莓派上，所以 Windows 原样运行会失败。

## 3. 改写方向

把原始导入：

```python
from lerobot.robots.xlerobot import XLerobotConfig, XLerobot
```

改成：

```python
from lerobot.robots.xlerobot import XLerobotClient, XLerobotClientConfig
```

把原始机器人创建：

```python
robot_config = XLerobotConfig()
robot = XLerobot(robot_config)
```

改成：

```python
robot_config = XLerobotClientConfig(remote_ip="192.168.10.240", id="my_xlerobot_pc")
robot = XLerobotClient(robot_config)
```

其他大部分逻辑保持不变：

```text
robot.connect()
robot.get_observation()
robot.send_action(action)
robot.disconnect()
```

这几个接口在 `XLerobot` 和 `XLerobotClient` 上都存在，所以这是官方路线里最自然的改法。

## 4. Host 端需要导入什么

最小 host 示例：

```python
from lerobot.robots.xlerobot.xlerobot_host import main


if __name__ == "__main__":
    main()
```

文件：

```text
E:\lerobot\host_client_examples\simple_xlerobot_host_runner.py
```

用到的包/函数：

```text
lerobot.robots.xlerobot.xlerobot_host.main
```

这个 `main()` 内部会做这些事：

```text
1. 创建 XLerobotConfig(id="my_xlerobot_pc")
2. 创建 XLerobot
3. robot.connect() 连接本地硬件
4. 创建 XLerobotHostConfig
5. 绑定 ZMQ 命令端口 5555
6. 绑定 ZMQ observation 端口 5556
7. 循环接收 client action
8. robot.send_action(action)
9. robot.get_observation()
10. 把 observation 发回 client
11. 超过 500ms 没收到命令时 robot.stop_base()
```

树莓派上其实可以直接用官方命令：

```bash
cd ~/xlerobot-dev/lerobot
source .venv/bin/activate
python -m lerobot.robots.xlerobot.xlerobot_host
```

新增 host runner 主要是教学用途，让你看到 host 脚本最小可以怎么写。

## 5. Client 端最小示例导入什么

最小 client 示例：

```text
E:\lerobot\host_client_examples\simple_xlerobot_client_control.py
```

主要导入：

```python
from __future__ import annotations

import argparse
import time
from typing import Any

from lerobot.robots.xlerobot import XLerobotClient, XLerobotClientConfig
```

每个包的作用：

```text
argparse
  解析命令行参数，例如 --ip、--move-base、--speed。

time
  控制底盘动作持续时间，并在循环里 sleep。

typing.Any
  给 observation 类型做标注，方便阅读和 IDE 提示。

XLerobotClientConfig
  官方 client 配置类，里面包含树莓派 IP、ZMQ 端口、机器人 ID 等。

XLerobotClient
  官方远程机器人 client 类，负责通过 ZMQ 连接树莓派 host。
```

## 6. Client 示例里写了哪些函数

### 6.1 build_client

```python
def build_client(ip: str, robot_id: str) -> XLerobotClient:
    config = XLerobotClientConfig(remote_ip=ip, id=robot_id)
    return XLerobotClient(config)
```

作用：

```text
创建一个官方 XLerobotClient。
```

关键参数：

```text
remote_ip="192.168.10.240"
  树莓派 host 的 IP。

id="my_xlerobot_pc"
  机器人 ID。建议和树莓派 host 当前校准文件 ID 对应。
```

### 6.2 print_observation_summary

```python
def print_observation_summary(observation: dict[str, Any]) -> None:
```

作用：

```text
打印 observation 里最重要的关节和底盘状态。
```

为什么不直接打印全部：

```text
后续 observation 里可能包含相机图像。
直接打印全部会非常长，不利于调试。
```

### 6.3 stop_base

```python
def stop_base(robot: XLerobotClient) -> None:
    robot.send_action({"x.vel": 0.0, "y.vel": 0.0, "theta.vel": 0.0})
```

作用：

```text
发送零速度，停止底盘。
```

为什么重要：

```text
所有 client 程序退出前都应该发送停止命令。
这是安全底线。
```

### 6.4 move_base_forward_briefly

```python
def move_base_forward_briefly(robot: XLerobotClient, duration_s: float, speed: float) -> None:
```

作用：

```text
让底盘以低速前进一小段时间，然后立刻停止。
```

它循环发送：

```python
{"x.vel": speed, "y.vel": 0.0, "theta.vel": 0.0}
```

最后调用：

```python
stop_base(robot)
```

安全设计：

```text
默认不运行这个动作。
必须显式加 --move-base 才会动。
默认速度只有 0.05 m/s。
默认持续 0.5 秒。
```

### 6.5 parse_args

```python
def parse_args() -> argparse.Namespace:
```

作用：

```text
解析命令行参数。
```

支持参数：

```text
--ip
  树莓派 IP，默认 192.168.10.240。

--id
  机器人 ID，默认 my_xlerobot_pc。

--move-base
  显式启用底盘小动作。

--duration
  动作持续时间。

--speed
  动作速度。
```

### 6.6 main

```python
def main() -> None:
```

作用：

```text
把整个 client 流程串起来。
```

流程：

```text
1. 读取命令行参数
2. 创建 XLerobotClient
3. robot.connect()
4. robot.get_observation()
5. 打印 observation 摘要
6. stop_base()
7. 如果传入 --move-base，执行低速短距离底盘测试
8. finally 中再次 stop_base()
9. robot.disconnect()
```

## 8. Xbox 示例怎么迁移

原始 Xbox 示例里可以保留：

```text
pygame 初始化手柄
get_xbox_key_state()
get_base_action()
get_base_speed_control()
SimpleTeleopArm
SimpleHeadControl
SO101Kinematics
左右臂 action 合并逻辑
```

需要替换：

```text
XLerobotConfig -> XLerobotClientConfig
XLerobot -> XLerobotClient
本地端口配置 -> 树莓派 IP 配置
```

原始：

```python
robot_config = XLerobotConfig()
robot = XLerobot(robot_config)
```

改成：

```python
robot_config = XLerobotClientConfig(remote_ip="192.168.10.240", id="my_xlerobot_pc")
robot = XLerobotClient(robot_config)
```

然后保持：

```python
robot.connect()
obs = robot.get_observation()
robot.send_action(action)
robot.disconnect()
```

## 9. 一个简化版 Xbox client 骨架

下面是骨架，不是完整成品：

```python
import pygame

from lerobot.robots.xlerobot import XLerobotClient, XLerobotClientConfig


def main():
    robot_config = XLerobotClientConfig(remote_ip="192.168.10.240", id="my_xlerobot_pc")
    robot = XLerobotClient(robot_config)
    robot.connect()

    pygame.init()
    pygame.joystick.init()
    joystick = pygame.joystick.Joystick(0)
    joystick.init()

    try:
        while True:
            pygame.event.pump()

            # 这里复用官方 5_xlerobot_teleop_xbox.py 的手柄读取逻辑
            # left_key_state = get_xbox_key_state(joystick, LEFT_KEYMAP)
            # right_key_state = get_xbox_key_state(joystick, RIGHT_KEYMAP)
            # base_action = get_base_action(joystick, robot)

            action = {
                "x.vel": 0.0,
                "y.vel": 0.0,
                "theta.vel": 0.0,
            }
            robot.send_action(action)

    finally:
        robot.send_action({"x.vel": 0.0, "y.vel": 0.0, "theta.vel": 0.0})
        robot.disconnect()


if __name__ == "__main__":
    main()
```

这个骨架说明了最重要的改造点：

```text
Windows 不再创建 XLerobot。
Windows 创建 XLerobotClient。
action 的生成逻辑仍然可以来自官方 Xbox 示例。
```
